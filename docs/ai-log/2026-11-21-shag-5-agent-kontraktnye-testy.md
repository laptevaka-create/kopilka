# Шаг 5 — делегированная часть: контрактные тесты отчёта и CSV-обмена

Дата: 2026-11-21. Исполнитель: агент. Проверка и приёмка: владелец проекта.

## Задача, поставленная агенту

После основной части шага 5 (отчёт месяца, экспорт и импорт CSV,
`CsvValidator` в Core, 297 тестов) делегировано: закрепить
контрактными тестами края против норматива `docs/specs/finance-rules.md`
(раздел `CsvValidator`) — строгий формат даты и високосная граница,
ISO-дата, лояльные суммы, пустые комментарии, кавычки в середине поля,
строка из «;;;;», круглый обмен с комментариями-«ловушками», округление
субкопеечных сумм, экспорт после навигации, файл с BOM, пустой файл,
недоступный путь, доли отчёта, независимость отчёта от фильтра
журнала, переход года; сверить спеку, README и дневник шага с кодом.
Дефекты `src/` не править, а описывать в отчёте. Правки существующих
файлов, коммиты и пуши запрещены.

## Независимая проверка

- Все четыре файла прочитаны целиком: тесты детерминированы,
  ожидания заданы явно, комментарии объясняют сценарии, стиль
  проекта выдержан.
- Арифметика долей пересчитана вручную: 1:1:2 → 25,0/25,0/50,0 % —
  ошибка была в задании владельца, агент закрепила верные значения.
  Поведение парсера кавычек проверено чтением `SplitCsvLine`:
  «аб"вг» действительно уходит в «незакрытая кавычка», «аб"вг"»
  снимается парой.
- Чистая пересборка без `bin/`/`obj`: 0 ошибок / 0 предупреждений;
  `dotnet test` — 133 Core + 181 App = 314, все зелёные (прогон
  повторён независимо от отчёта).
- `git status`: существующие файлы агентом не тронуты; её вклад —
  ровно четыре новых файла.

## Правки по итогам проверки

- `docs/specs/finance-rules.md`: в правило суммы добавлено округление
  субкопеечных значений (половина от нуля вверх; округлившееся к нулю
  — отказ); в правила проверки строки добавлено правило кавычки
  внутри некавычного поля (незакрытая — отказ; парная снимается,
  лояльный CSV; экспорт оборачивает такие поля целиком, круглый обмен
  без потерь). Оба правила уже существовали в поведении и закреплены
  тестами — спека приведена к факту.
- Добавлен тест владельца `PairedQuotesInsideUnquotedField_AreStripped_
  AsDocumented` (в `CsvValidatorTests.cs`): зафиксировать
  документированное поведение парных кавычек. Итог — 315 тестов
