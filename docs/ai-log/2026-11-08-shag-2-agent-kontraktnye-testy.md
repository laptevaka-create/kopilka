# Шаг 2 — делегированная часть: контрактные тесты моделей представления

Дата: 2026-11-08. Исполнитель: агент. Проверка и приёмка: владелец проекта.

## Задача, поставленная агенту

После основной части шага 2 (MVVM-каркас, журнал месяца, диалог
добавления, 111 тестов) делегировано: довести покрытие моделей
представления до контрактного — пустые и односторонние месяцы, февраль
обычного и високосного года, многократная навигация через границы года,
заголовки всех 12 месяцев, лояльность парсера сумм, границы
`MoneyText`, команда с параметром; сверить дневник шага 2 и статус
README с кодом. Дефекты `src/` не править, а описать в отчёте. Коммиты
и правки существующих тестов без причины запрещены.

## Что выполнил агент

- 31 новый тест в трёх файлах `tests/Kopilka.App.Tests/`:
  - `MainViewModelContractTests.cs` (6 фактов + теория на 12 месяцев):
    пустой месяц (итоги «0,00 ₽»), месяц только с доходами, месяц
    только с расходами и отрицательное сальдо с минусом, февраль
    невисокосного и високосного года (28/29 февраля, соседи excluded),
    14 шагов вперёд и 25 назад с многократным пересечением границ года,
    все 12 русских заголовков;
  - `TransactionEditContractTests.cs` (5): пробелы внутри числа
    («1 2 5 0» → 1250 ₽), ведущий плюс, «0,001» округляется к нулю —
    отказ «больше нуля», повторный Save после ошибки, два успешных
    Save подряд;
  - `MvvmInfrastructureContractTests.cs` (8): копейки и субрублёвые
    суммы, триллионы с полной группировкой U+00A0, `long.MaxValue`
    без переполнения, точный текст `FormatSigned` (минус — U+2212),
    команда с параметром, реакция подписчика на
    `RaiseCanExecuteChanged`, раздельные уведомления двух свойств.
- Сборка 0 ошибок / 0 предупреждений; 142/142 теста зелёные.
- Сверка дневника шага 2 и статуса README с кодом: совпадает
  (построчная проверка всех заявленных свойств, чисел и имён).
- Вскрытый дефект: `TransactionEditViewModel.Save` не сбрасывает
  `ValidationSummary` при успешном сохранении — после ошибочной
  попытки сводка остаётся устаревшей. Агент корректно не правил код
  и описал сценарий с предложением минимального исправления.
- Честная оговорка в отчёте: первое прохождение навигационного теста
  дало расхождение из-за собственной арифметики теста (+14 месяцев),
  код навигации был корректен — тест исправлен самим агентом до сдачи.
